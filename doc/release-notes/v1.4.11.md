# RCPU Core v1.4.11 Release Notes

This is a wallet-availability and release-engineering maintenance release.
It contains no consensus parameter changes and does not modify the 27,326
activation height.

## Fixes

- **Legacy wallet change:** wallets without a confidential descriptor manager
  no longer force a CONFIDENTIAL change output. Confidential UTXOs are
  excluded from automatic coin selection for those wallets, and preselected
  confidential inputs fail with an actionable error instead of an obscure
  `ReserveDestination` failure.
- **Dust change:** `SelectionResult::GetChange()` again enforces
  `min_viable_change`, so small change is paid to the miner instead of being
  inserted as a dust output.
- **Release signing isolation:** the GUI signing key is imported only in the
  publish job, not in the AppImage build job that executes third-party
  tooling.
- **Windows PFX cleanup:** the temporary signing PFX is removed on failure as
  well as success.

## Tests

- `coinselector_tests`: 14/14
- `tx_verify_tests`: 15/15
- `blind_tests`: 30/30

The 27,326 strict-nonce rules and the historical H-1 explicit-zero discussion
are unchanged by this release. Recent v1.4.5-v1.4.10 nodes already agree on
the explicit-zero rule; only v1.4.4 and earlier are incompatible.
