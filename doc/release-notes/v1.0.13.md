# RCPU Core version v1.0.13

Security release. No consensus change. Tag v1.0.12 (`76ab1ab`) remains
the fee-output UTXO fix; this tag only changes local blinding math and
how notify commands are launched.

Source: PR #14 (`fix(security): H-1 ECDH constant-time; H-2 safe runCommand`).
Tag target after the version bump: `MERGE_SHA`.

## Security

### Confidential blinding (H-1)

`BlindOutputToRecipient` / `UnblindValueWithKey` no longer derive the
shared nonce with `secp256k1_ec_pubkey_tweak_mul` + compressed
serialize. They call `secp256k1_ecdh` and copy the shared-point
x-coordinate (`CopyX32`).

The x-coordinate is the same as before, so existing blinded outputs
stay unblindable. The constant-time guarantee comes from libsecp256k1's
ECDH path, not from the callback.

The secp256k1 subproject is now configured with
`--enable-module-ecdh` (it was `--disable-module-ecdh`).

### Notify command launch (H-2) — breaking for shell syntax

`runCommand()` no longer calls `system()` / `_wsystem()`.

- POSIX: tokenize (quote-aware) → `fork` + `execvp` + `waitpid`
- Windows: `CreateProcessW` (does not start `cmd.exe`)

`alertnotify`, `blocknotify`, `walletnotify`, and any other
`runCommand` caller **no longer interpret** `|`, `;`, `&&`, `||`,
`>`, `<`, `` ` ``, or `$()`.

If a notify line needs a pipeline, point it at a script:

```
blocknotify=/usr/local/bin/rcpu-block.sh
```

and put the pipeline inside that script. Paths with spaces must be
quoted by the operator; the POSIX tokenizer strips matching quotes.

Windows never supported the wallet `%w` placeholder (upstream
exclusion). That is unchanged.

## Not in this release

P2P peer-identity authentication (working title H-3) is **not**
included. The sketch was not wired into `net_processing`, did not
persist an identity key, and is not on `main`.

`ShellEscape()` is still used for POSIX `%w` substitution in
`wallet.cpp`. That is leftover quoting for a shell that `runCommand`
no longer invokes. Tracked separately; not required to run v1.0.13.

## Upgrade

1. Stop `rcpu-qt` / `rcpud`. Confirm RPC port 7337 is closed.
2. Back up `%APPDATA%\RCPU\rcpu\` (or `~/.rcpu/rcpu/`) and the conf
   file. Record `bestblockhash` if you want a same-chain check.
3. Install binaries whose user agent is `/RCPU:1.0.13/`.

   If a version-bump commit is not created and the tag is applied to
   the PR #14 merge directly, the binaries still report
   `/RCPU:1.0.12/` and this line must be changed back.
4. Restart **without** `-reindex` or `-reindex-chainstate`.
   This release does not change UTXO membership.

Review every `*notify=` line in `rcpu.conf` / `settings.json` before
restart. A value that relied on `/bin/sh -c` will now exec the first
token only.

Windows datadir is `%APPDATA%\RCPU\rcpu\`, not `%APPDATA%\RCPU\`.

## Compatibility

- Consensus and wire format: unchanged from v1.0.12.
- Blinded outputs created by ≤ v1.0.12 remain valid to unblind.
- Old nodes keep launching notify strings through a shell. New nodes
  do not. This is local process behavior only.
- Mixed-version P2P is fine; there is no new handshake message.

## Rollback

Stop the node. Restore the v1.0.12 binaries. Datadir and chainstate
do not need to be rolled back for this upgrade. Notify lines that you
rewrote for v1.0.13 may need the old shell syntax if you go back.
