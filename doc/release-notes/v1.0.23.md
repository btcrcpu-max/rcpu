# RCPU Core v1.0.23 Release Notes

## Mainnet Base58 addresses

- Base58 **address** encoding (`1...` / `3...`) is restored on mainnet, so
  addresses round-trip with Bitcoin address tooling (decoding was already
  allowed).
- Unchanged: WIF private keys (`EncodeSecret`) remain disabled on mainnet,
  and wallet RPCs (`getnewaddress` / `getrawchangeaddress`) still reject
  `legacy` output types.
- See `doc/address-format.md` for the exact compatibility matrix.

## P2TR Path-B unblind fix

Fixed unblinding of P2TR Path-B confidential outputs: the wallet now resolves
the taproot spend key (`GetPrivKey`) when scanning, so balances, change and
history show the real amounts instead of 0 for these outputs.
