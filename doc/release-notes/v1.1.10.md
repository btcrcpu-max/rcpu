# RCPU Core v1.1.10 Release Notes

> **Status:** Released 2026-10-02. Consensus height 12748 frozen at tag time.

## Path A (legacy nonce) soft-fork ban

- `nBanPathAHeight` is scheduled for **12748** on mainnet.
  - Computed from live tip **10732** at build time (2026-10-01) with
    **2016-block** notice window: `H = T + 2016 ≈ 7 days` at 5-minute blocks.
  - Height confirmed from live tip **10732** + 2016-block notice window.
    Frozen at tag time; no further recomputation needed.
- Note: this height was recomputed at build time from the live tip (10732) and
  may differ from earlier drafts that used 12696 (based on tip 10680), 12701 (based on tip 10685), 12713 (based on tip 10697) or 12735 (based on tip 10719).
- At and above this height, **new Path A (`0x02`) outputs in transactions are**
  **rejected by consensus rules** in blocks and mempool.
- **Historical Path A UTXOs remain spendable, scannable and unblindable** —
  this is a forward-only soft-fork that does not invalidate existing outputs.
- Wallets that have not upgraded and still create Path A transactions after
  this height will see them rejected by the network. Upgrade to a build
  containing A-v2 / B-v2 / `f56f75b` (or later) before the height is reached.

## Wallet-layer changes

- **A-v2 (`efc8789`)**: broadcast failures are now surfaced to the caller
  (`-4` RPC error, `MSG_ERROR` GUI popup) instead of silently discarded.
- **B-v2 (`7bdb5b1`)**: automatic coin-selection skips unconfirmed
  confidential outputs, preventing the creation of oversized v3-child
  transactions that would be rejected by the mempool.
- Manual coin-control / PSBT construction is unaffected — users can still
  explicitly select unconfirmed CT inputs if desired.
