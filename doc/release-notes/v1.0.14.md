# RCPU Core version v1.0.14

Security release. No consensus change, no `-reindex` needed. Tag v1.0.13
(`fcf79de`) remains the "sha256sum bundles exist" baseline; this tag only
changes the private-key comparison path and the notify `%w` substitution.

Source: PR #16 (`fix(crypto): constant-time CKey compare (M-1)` plus the
wallet `%w` change).

## Security

### M-1: constant-time CKey / CExtKey comparison

`CKey::operator==` and `CExtKey::operator==` no longer compare the secret
material with `memcmp`. They now use a short-circuit on `fCompressed` and
size, treat `size() == 0` as equal without touching memory, and compare the
remaining bytes with a constant-time `FixedTimeEquals` loop. This removes a
data-dependent branch against secret key material.

### walletnotify `%w` substitution

In the `-notifytxchanged`-style command, the `%w` placeholder is now
replaced with the wallet name directly on all platforms (previously it was
wrapped in `ShellEscape` and skipped entirely on Windows). Notify commands
still do not go through a shell, unchanged from v1.0.13 (H-2).

## Not in this release

- H-3 (pending further review)
- M-2 / M-4 (fee-path scan + extra test coverage, own PRs)
- automated CI release signing

## Upgrade

After installing the new binaries, the network user agent becomes
`/RCPU:1.0.14/`. No reindex, no data directory migration required.
