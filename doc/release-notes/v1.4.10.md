# RCPU Core v1.4.10 Release Notes

This maintenance release follows the 27,326 strict CT nonce activation and
hardens the remaining Path-A edge cases.

## Fixes

- **BlindTransaction Path-A gate:** `BlindTransaction` now rejects the legacy
  Path-A (`0x02` plaintext nonce) fallback when the spend height reaches
  `nCTStrictRulesHeight`, including callers outside the wallet.
- **`-ctlegacy` boundary:** the wallet now evaluates the legacy-nonce ban at
  `tip + 1`, closing the one-block window at the activation height.
- **Tests:** added positive `0x03`/`0x04` nonce validation coverage, a Path-A
  strict-height regression test, and updated older blind tests to the current
  M-2 fail-closed semantics.

## Audit evidence

- Blocks 9992-27326 on mainnet were scanned for v3
  `SIGHASH_SINGLE`/`SIGHASH_SINGLE|ANYONECANPAY`: 2,587 v3 transactions,
  38,438 signatures, zero findings.
- `tx_verify_tests`: 15/15 passed.
- `blind_tests`: 30/30 passed.

No consensus parameter changes are included in this release.
