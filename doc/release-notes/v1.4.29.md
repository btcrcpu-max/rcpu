# RCPU Core v1.4.29 release notes

Icon-only release.

The RCPU artwork is a round badge on an opaque near-white plate, so Windows drew
the desktop shortcut, the taskbar entry and the window icon as a hard-edged
square. The plate now carries a rounded-rectangle alpha mask (radius = 22% of the
shorter side):

- `rcpu.ico` - embedded in `rcpu-qt.exe`, so Explorer and the taskbar use it;
- `rcpu.png` - window and taskbar icon, and the AppImage desktop entry;
- `share/pixmaps/rcpu.ico` - the NSIS installer and the shortcut it creates.

The `.ico` keeps the 16/32/48/64/128/256 set; every frame is resampled from the
256 px master so the corner radius stays proportional instead of being cropped.

## Compatibility

- Consensus: unchanged. No reindex required.
- Wallet: no migration.
- RPC: unchanged.
- GUI: no behaviour change; only the artwork differs.

An existing install keeps the old icon until it is upgraded to this build (or the
shortcut is repointed at a rounded `.ico` by hand).
