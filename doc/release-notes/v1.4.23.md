# RCPU Core v1.4.23 release notes

v1.4.23 fixes how the GUI reports confidential amounts it cannot read, and
completes the Simplified Chinese translations for the new transaction
filters and details. **No consensus change, wallet migration, or RPC change.**

## GUI fixes

### Overview page no longer shows unknown amounts as zero

The "Recent transactions" list on the Overview page read the numeric amount
only, so a confidential output the wallet cannot unblind was rendered as
`0.00000000 RCPU`, while the Transactions tab correctly showed `—` for the
same transaction. Both views now use `—`, which means *unknown*, not zero.

### "Needs review" filter label

The label was clipped when the filter row was tight. It now reserves enough
width for the translated text.

## Translations (Simplified Chinese)

New Chinese strings for the CT amount-status UI, which previously fell back
to English:

- `Needs review` → 需要复核, plus its tooltip.
- `Unreadable outputs` block in the transaction details dialog: the heading,
  the per-output line, the reasons (`wallet locked`, `watch-only, no key`,
  `cannot decrypt`) and the "unknown, not zero" note.
- The three amount tooltips on the Transactions tab (`locked`, `no_key`,
  `unreadable`).

English builds are unchanged.
