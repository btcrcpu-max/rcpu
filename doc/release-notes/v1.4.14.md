# RCPU Core v1.4.14 Release Notes

**Hard fork at block 29,909** (mainnet/testnet; expected 2026-11-23). All
nodes, pools and miners must upgrade before that height.

## Consensus: H-1 dual-algo ASERT re-anchor

The two proof-of-work algorithms previously shared an absolute ASERT anchor:
`nTimeDiff` was measured against the last block of *either* algorithm, while
`nHeightDiff` counted only the algorithm being evaluated. An algorithm that
was idle for a long time therefore accumulated unbounded "lateness credit",
which could then be released as a run of `powLimit`-difficulty blocks.

v1.4.14 records each algorithm's last block and current ASERT anchor in
`CBlockIndex`. If the gap since the last block of the algorithm exceeds
`nDualAlgoReanchorGap` (12 hours), the algorithm re-anchors to its next block
and the one-time target increase is capped at `nDualAlgoMaxDrop` (8x). The old
credit is discarded; the resume block becomes the next anchor.

Activation height: **29,909** (`nDualAlgoLatenessFixHeight`). Before that
height the original formula is used unchanged. This is a hard fork: nodes at
v1.4.13 or older can reject blocks after the activation height if a low-hashrate
algorithm re-anchors.

## Assumeutxo: CT-aware hash_serialized_4

`gettxoutsetinfo` accepts `hash_type=hash_serialized_4`, which commits to the
full `CTxOut` (commitment, nonce, rangeproof) instead of the legacy
`hash_serialized_3` (explicit amount and script only). `AssumeutxoData` gains
an optional `hash_serialized_ct`; CT chains without it are refused on snapshot
load rather than falling back to the CT-blind hash. RCPU `m_assumeutxo_data`
remains empty; operators must generate `hash_serialized_ct` from a synced node
before enabling assumeutxo.

## Network / release hardening

- A known header prefix followed by one bogus child no longer causes full
  HashimotoLight re-verification of the known prefix; only the unknown suffix
  is verified.
- Windows Authenticode signing now fails closed: a missing certificate or
  installer aborts the tag release, and every portable EXE is signed and
  verified before the ZIP is rebuilt.
- Linux release builds run the RandomX parity gate and the RandomX/PoW/dual-algo
  test suites.

## Verification

- S1 Linux build: three named regression tests pass; 85 affected test cases
  pass.
- Mainnet replay at tip 27,893 with activation 29,909: 0 old/new mismatches,
  0 re-anchors. Historical replay from 21,000 shows exactly one re-anchor at
  27,104 after a 14.36h Etchash gap; first-block target change ~1.23x, well
  below the 8x cap and not `powLimit`.

## Upgrade

Download v1.4.14, verify `SHA256SUMS.txt.asc` with the RCPU release key, and
restart before block 29,909. Windows installers are Authenticode-signed.
