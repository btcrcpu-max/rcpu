# RCPU Core v1.4.22 release notes

v1.4.22 is a GUI and branding follow-up to v1.4.21. It adds the artwork banner
to the Overview page and points the project links at the new official sites.
**No consensus change, wallet migration, or RPC change.**

## GUI

### Overview page banner

The Overview page now shows the RCPU artwork in the free space under the
balances box, right below the **总额** (total) row.

- The image is compiled into the binary as a Qt resource, so it ships with
  every build (no external file to install).
- It is centred and scaled with preserved aspect ratio, capped at 280×280 so
  it never looks stretched. On a smaller window it shrinks to fit; on a
  HiDPI screen it is rendered at the native device pixel ratio.
- The artwork's paper background was converted to an alpha channel, so the
  sketch blends directly into the panel instead of showing a grey rectangle.

## Project links

- Mining pool now points to `https://pool.rcpuapp.top/`.
- The retired Web Wallet link (`https://rcpu.top/`) was removed.
- The official website `https://rcpuapp.top/` was added to `README.md`,
  `docs/nodes/README.md` and the Windows readme.
- The Authenticode signer info URL embedded in the Windows installer and
  portable binaries now points to `https://rcpuapp.top/`. The already
  published v1.4.21 installers still carry the old URL; v1.4.22 is the first
  release with the new one.

DNS seeds (`seed1.rcpu.top` … `seed3.rcpu.top`) are unchanged.
