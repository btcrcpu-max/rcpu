# RCPU Core v1.4.12 Release Notes

This release contains wallet and repository-hygiene fixes. It does not change
consensus parameters and does not change the 27,326 strict-nonce activation
height.

## Fixes

- **R-1 confidential change:** a blinded input paying an explicit recipient no
  longer loses a small change amount to the explicit-change dust threshold.
  `GetChange()` still enforces `min_viable_change` for explicit change, but a
  confidential change is kept when it is needed to balance the Pedersen
  commitment.
- **R-3 line endings:** the v1.4.11 tree accidentally stored several C++ and
  workflow files as CRLF. Those files are normalized back to LF and
  `.gitattributes` now pins source/workflow text files to LF.
- **R-5 stale comment:** the `spend.cpp` comment around the blinded-input
  explicit-recipient guard now describes the fail-closed behavior that is
  actually implemented.
- **R-2 migration documentation:** legacy wallets that hold blinded UTXOs are
  excluded from automatic selection; `doc/wallet-ct-migration.md` documents
  the descriptor-wallet migration path.

## Tests

- `coinselector_tests`: 14/14
- `tx_verify_tests`: 15/15
- `blind_tests`: 30/30

The v1.4.11 wallet fixes for H-2 (forced confidential change), M-1
(`min_viable_change`) and the GUI release-signing isolation are retained.
