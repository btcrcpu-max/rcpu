# RCPU Core v1.0.22 Release Notes

## Mining RPC

- `computerandomxhash` now returns the **computed hash** in mining mode
  (previously it returned the work object without the evaluated hash).
- Pools must run **v1.0.22 or later** to evaluate shares with this RPC;
  older node versions do not provide the new hash result.

## Included commits

- `89e2fa3` fix(rpc): computerandomxhash returns computed hash in mining mode
- `3225f4c` release: bump version to v1.0.22
