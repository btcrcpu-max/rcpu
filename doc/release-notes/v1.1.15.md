# RCPU v1.1.15 Release Notes

## Bug Fixes

### Fix CT change output disappearing after wallet re-locks (N-02)

**Problem:** After sending a confidential transaction (CT), if the wallet auto-locked (passphrase timeout), the change output would disappear from the balance until `rescanblockchain` was run.

**Root Cause:** `CommitTransaction()` stored the blinded transaction in the wallet, but `AvailableCoins()` needed to unblind CT outputs to get their real values. If the wallet was locked, `UnblindWalletOutput()` failed to retrieve the blinding key, causing the change output to be skipped.

**Fix:** 
1. In `CommitTransaction()` (wallet.cpp): Pre-unblind all CT outputs while the wallet is still unlocked, and cache the real amounts in `wtx->mapValue`.
2. In `AvailableCoins()` (spend.cpp): Check the cached amount first before attempting real-time unblinding.

## Impact
- All users with passphrase-encrypted wallets should upgrade.
- After upgrading, send a test CT transaction and verify the change output remains visible after wallet locks.
