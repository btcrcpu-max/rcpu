# RCPU Core v1.1.6

No consensus change. No reindex.

## Changes

- CI: make-check uses a real line continuation and fail-closed
  assertions that the ten scoped unit suites actually ran (#53).
- Docs: man page names and `gen-manpages.py` target rcpud, rcpu-cli,
  rcpu-tx, rcpu-wallet, rcpu-util, rcpu-qt (#53).
- Docs: add v1.1.5 notes and a v1.1.1–v1.1.4 index (#53).
- Release: Windows packaging accepts only
  `rcpu-${VERSION}-win64-setup.exe` (fallback `rcpu-*-win64-setup.exe`).
  Empty or <1MB stubs fail the job (#54).
- Build: renormalize `depends/gen_id` to LF (#54).

## Not in this release

- No change to PoW, CT rules, ports, subsidy, or chainwork.
- `chainTxData` remains the placeholder until filled from
  `getchaintxstats 4096` on a synced node.
- Unit test binary remains `test_bitcoin` (`RCPU_TEST_NAME` unused).

## Follow-up (main only, not in the v1.1.6 tag tarball)

- Docs: regenerate `doc/man/rcpu*.1` with help2man from the v1.1.6
  binaries on CI (headless `QT_QPA_PLATFORM=offscreen`) and apply the
  resulting `man.patch`.
