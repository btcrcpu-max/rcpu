# RCPU Core v1.3.8 Release Notes

> **Status:** released (tag `v1.3.8`). This is a **P2P hardening release**, not a
> consensus change. It does not change the Etchash rule: nodes, pools and miners
> that validate bit-30 blocks at/after 21,000 must already run the v1.3.7+
> big-endian rule.

## Fixed: Etchash header replay could burn CPU

`ProcessHeadersMessage()` ran `CheckHeadersPoW()` before checking whether the
batch was already known. Replaying 2,000 public Etchash headers made the node
run a full `HashimotoLight()` per header (about 5 seconds of CPU per 224 KB
message), and alternating epochs also thrashed the 2-entry epoch cache.

v1.3.8:

- Checks the last header against the block index (and the batch continuity)
  **before** `CheckHeadersPoW()`. A known/ancestor batch is accepted without
  re-running PoW; it was already verified when it was first accepted.
- Charges a generous per-peer header budget (20,000-header burst, 2,000
  headers/s refill) before `HasValidProofOfWork()`. This is a backstop for new
  headers; normal headers sync is not throttled, and the known-header early-out
  removes the cheap replay vector entirely.

No consensus rule changes. Headers are still fully verified in
`AcceptBlockHeader()`; the context-free `CheckBlock()`/disk paths are unchanged.

## Added: mainnet-21000 KAT

`dualalgo_tests` now pins the mainnet parameters used by the activation:

- `GetEtchashEpoch(20999) == -1`, `21000 == 0`, `26999 == 0`, `27000 == 1`;
- `GetEtchashSeedHash(21000).IsNull()`;
- bit-30 below 21,000 dispatches RandomX, at/after 21,000 dispatches Etchash;
- bit-30 clear remains RandomX.

## Upgrade

- **Consensus-critical:** keep running v1.3.7 or later for the big-endian
  Etchash rule before block 21,000.
- v1.3.8 is recommended for all public nodes, especially nodes that relay
  headers after 21,000.
- Companion versions remain: miner **1.0.23+**, Miningcore pool with the
  big-endian target and raw `etchash_seed_hash` patch.

## Compatibility

- No change to blocks, transactions, CT rules, wallet formats or the Etchash
  result byte order.
- Asset names: `rcpu-1.3.8-*`.

## Verification

- `make check` unit scope includes `dualalgo_tests` (new mainnet KAT) and
  `pow_tests`.
- Functional suites: `feature_dualalgo_count_cache.py` and the RCPU CT wallet
  suites.
- CI: `build`, `make-check`, `functional tests`, `source build + regtest smoke`
  and `docker build` pass on the release commit.
