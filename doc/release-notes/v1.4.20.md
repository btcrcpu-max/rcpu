# RCPU Core v1.4.20 release notes

v1.4.20 is a translation-only follow-up to v1.4.19. It fixes the Simplified
Chinese Overview page so the confidential-amount unlock control no longer falls
back to English. **No consensus change, wallet migration, or RPC change.**

## GUI translation

When the wallet is locked, the Overview page now displays:

- Button: `解锁机密金额` (previously `Unlock to see confidential amounts`).
- Tooltip: `钱包锁定时会隐藏机密金额，且上方余额不包含这些金额。`
- Unlocked state: `已解锁` (existing translation retained).

The translations are included for the `zh_CN`, `zh-Hans`, and generic `zh`
locales. All v1.4.19 confidential-amount reporting, filtering, coin-control,
and support-export behavior is unchanged.
