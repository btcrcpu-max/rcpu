# RCPU Core version v1.0.11

RCPU Core v1.0.11 是纯文档与卫生清理版本，**无共识规则变更、无数据结构变更**。

## 变更内容

### 文档与卫生

- **`INSTALL.md`**：安装包名统一为真实 GitHub Releases 资产名
  `rcpu-${VERSION}-x86_64-linux-gnu.tgz`，并指引查看 `docs/nodes/README.md`
  获取各 Release 精确资产名。
- **`doc/release-notes.md`**：用简短 RCPU 索引替换 Bitcoin Core 27.0 上游模板，
  指向 `doc/release-notes/v1.0.x.md`。
- **`doc/release-notes/v1.0.10.md`**：移除「docs 指向 v1.0.9」的过时描述。
- **`contrib/README.md`**：不再提及当前未发布的 `SHA256SUMS.asc`
  （当前 Release 只发布 checksum 文件）。
- **`SECURITY.md`**：明确「如发布有签名则使用仓库内 GPG key」。
- **`.github/PULL_REQUEST_TEMPLATE.md`**：清理 bitcoin-core/gui 上游残留表述。

### 版本

- 版本号升至 **1.0.11**（`configure.ac` / `src/clientversion.h`）。

## 升级说明

- 本版本无共识规则变更、无数据结构变更，只需替换二进制；历史区块与新规则完全兼容，不需要重新同步或 reindex。
- 上一版本（v1.0.10）的所有修复与文档对齐继续有效。
- 显式 coinbase 强制规则（自 v1.0.9 起）继续生效。
