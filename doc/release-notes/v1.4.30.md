# RCPU Core v1.4.30 release notes

Icon-only release.

v1.4.29 rounded the plate behind the icon, but the plate stayed opaque white, so
the desktop showed a white tile with a badge on it rather than the badge itself.
The plate is now removed: the near-white background is taken out of the original
artwork, with the last few pixels feathered so the circular edge stays smooth.
The four corners are fully transparent.

The change covers every place the icon is used:

- `rcpu.ico` - embedded in `rcpu-qt.exe`, so Explorer, the taskbar and the
  window title bar pick it up;
- `rcpu.png` - window and taskbar icon, and the AppImage desktop entry;
- `share/pixmaps/rcpu.ico` - the NSIS installer and the shortcut it creates.

The `.ico` keeps the 16/32/48/64/128/256 set, each frame resampled from the
256 px master.

## Compatibility

- Consensus: unchanged. No reindex required.
- Wallet: no migration.
- RPC: unchanged.
- GUI: no behaviour change; only the artwork differs.

An existing install keeps the old icon until it is upgraded to this build. After
upgrading, Windows may keep showing the cached icon for a while; restarting
Explorer (or clearing the icon cache) refreshes it.
