# RCPU Core version v1.0.10

RCPU Core v1.0.10 是构建 / 文档 / 测试 / 品牌收敛版本，无共识规则变更。

## 变更内容

### 构建

- **Dockerfile 补齐 RandomX**：builder 阶段按 `ci.yml` 同一套参数构建 RandomX v1.2.1（同一 SHA256 校验 + `depends/patches/randomx/custom_configuration.patch` + 共享库安装），runtime 镜像补齐 `librandomx.so` 与 `libevent-pthreads`；`docker-smoke.yml` 改为真实执行 `docker build`。
- **源码编译文档统一指向 `scripts/build-randomx.sh`**：`README.md` / `INSTALL.md` / `docs/nodes/README.md` / `doc/release-process.md` 的"从源码编译"步骤不再裸跑 `./configure`（本地按旧文档会因缺少 RandomX 直接失败），统一先安装依赖并执行脚本（脚本内对 tarball 做 SHA256 校验并打同一 patch）。
- `doc/README_windows_rcpu.txt` 重写：移除 Bitcoin Core 模板文案（`bitcoin-qt.exe`、bitcoin 维基），改为 `rcpud` / `rcpu-cli` 的 RCPU 说明。

### 测试

- 修复 Issue #6：`make check` 在 genesis 上 assert 的问题。`UpdateFlagsForBlock`（`validation.cpp`）对祖先为空（genesis / 测试夹具激活链）的 `pindex` 加空指针护栏，BIP30/BIP34 祖先判定仅在存在 `pprev` 时执行。
- CI 的 `Test` 步骤新增 `group_outputs_tests` 套件，防止类似回归再无声通过。

### 共识参数文档（仅文档，不改代码）

- `nMinimumChainWork`：文档从已回退的 height-3,600 值 `...01fc87aa3c` 改回与代码一致的 height-100 实测值 `...0001940138`（v1.0.8 为修复空目录 IBD 下调）。升级路线图同步更新：Tier 2 的 checkpoint / assumevalid（3,600）已完成；Tier 2 的 chainwork 部分未落地；Tier 3 必须用已同步节点的 `getblockchaininfo.chainwork` 再抬，禁止手填旧文档数字。
- `chainTxData` 标注为 genesis 占位、不用于共识；待同步节点提供 `getchaintxstats` 实测值后填。

### 品牌与卫生

- 版本号升至 **1.0.10**（`configure.ac` / `src/clientversion.h`）；`docs/nodes/README.md` 安装示例指向最新已发布版本 v1.0.9。

## 升级说明

- 本版本无共识规则变更、无数据结构变更，只需替换二进制；历史区块与新规则完全兼容，不需要重新同步或 reindex。
- 上一版本（v1.0.9）引入的显式 coinbase 强制规则继续生效。
