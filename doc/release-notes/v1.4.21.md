# RCPU Core v1.4.21 release notes

v1.4.21 is a translation-only follow-up to v1.4.20. It adds a Simplified
Chinese translation for the wallet error shown when a send can only be funded
by unconfirmed confidential outputs. **No consensus change, wallet migration,
or RPC change.**

## GUI translation

When a second transfer is blocked because the spendable balance sits only in
unconfirmed confidential outputs, the send dialog now shows, for Simplified
Chinese locales:

- `此笔转帐需要等上一笔转帐确认后才能发送`

Previously this message fell back to English:

```
Insufficient funds: the requested amount is only available in unconfirmed
confidential outputs; wait for confirmation and try again
```

The English source string is unchanged, so English builds continue to show it
in English. The translation is included for the `zh_CN`, `zh-Hans`, and generic
`zh` locales. The underlying coin-selection behavior (refusing to spend
unconfirmed confidential outputs) is unchanged — this release only translates
the message.
