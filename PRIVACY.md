# RCPU Core Privacy Policy

RCPU Core is self-hosted peer-to-peer node software.

- It does not include telemetry, analytics, advertising, or tracking.
- Wallet private keys and wallet data remain in the local data directory and
  are never sent to the RCPU project.
- As a peer-to-peer node, RCPU exchanges public blockchain data (blocks and
  transactions) with peers. Like any P2P software, peers can observe the IP
  address used for those connections. This is inherent to participating in the
  network, not telemetry sent to the project.
- The Windows installer does not collect or transmit user data.
- The project website may keep standard web-server access logs for security and
  abuse prevention.

Questions: open an issue at https://github.com/btcrcpu-max/rcpu/issues
