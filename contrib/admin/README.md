# Admin / Operational Scripts

This directory contains operational and maintenance scripts used
by the RCPU infrastructure team.

> **Note:** These scripts are for internal infrastructure use.
> They may contain site-specific configuration and are not
> required for building or running RCPU Core.

## Files

| Script | Description |
|--------|-------------|
| `backup.js` | Database backup utility |
| `current_proxy.js` | Stratum proxy service |
| `check_gbt.py` | GetBlockTemplate validation checker |
| `check_pool_status.py` | Mining pool health monitor |
| `read_full_proxy.py` | Proxy log reader utility |
| `run_backup.bat` | Windows backup runner |
| `rcpu.service` | systemd service unit for rcpud |
